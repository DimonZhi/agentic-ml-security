# База знаний: безопасность Auto & Agentic ML

Контекст и задачи — в [описании проекта](PROJECT.md).
Начните с [общей сводки](knowledge/SUMMARY.md). В ней есть выводы и ссылки на все материалы.

## Структура

```text
AGENTS.md                     правила для агента
PROJECT.md                    описание проекта и задачи исследования
context/
  brainstorm.md               оцифрованный брейншторм команды
research/
  TEMPLATE.md                 шаблон research-карточки
  <тема>.md                   research-карточки участников
knowledge/
  SUMMARY.md                  общая сводка и список материалов
  TEMPLATE.md                 шаблон статьи
  articles/                   все карточки в одной папке
    cbr-ai-security.md
    nvidia-code-execution-agentic-risks.md
    owasp-agentic-top-10-2026.md
    owasp-llm-top-10-2026.md
  files/                      локальные копии оригиналов, на них ссылаются карточки
```

Каждая статья хранится один раз. Для поиска и связей используются теги и ссылки.

## Добавить research-карточку

Скопируйте [шаблон](research/TEMPLATE.md) в `research/<тема>.md` и заполните его, или попросите агента:

> Создай research-карточку по теме <тема>, owner <имя>. Следуй AGENTS.md.

Агент создаст файл по шаблону и задаст трудный вопрос, а мнение, гипотезу и ответ пишет owner.

## Добавить статью через агента

Откройте репозиторий в агенте, который может читать и менять его файлы, и напишите:

> Добавь в базу знаний статью: <ссылка>. Следуй AGENTS.md и обнови summary.

Агент прочитает источник, проверит дубликаты и добавит карточку в `knowledge/articles/`.
Затем пересоберёт общую сводку по всем карточкам. Если источник недоступен,
он сохранит ссылку с отметкой и не будет выдумывать содержание.

Чтобы обновить всё после ручных правок:

> Пересобери summary базы знаний по текущим карточкам статей.

Если ваш инструмент не подхватывает `AGENTS.md` автоматически, попросите его прочитать
[правила](AGENTS.md) перед работой. Обновление выполняет вызванный агент с доступом к источнику
и репозиторию; фонового сервиса здесь нет.

Карточки и сводка — разборы источников, а не результаты экспериментов команды.
