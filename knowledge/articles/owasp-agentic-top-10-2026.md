# OWASP Top 10 for Agentic Applications 2026

## Коротко

[OWASP](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/) выделяет риски автономных агентов.
Обзор категорий прочитан в [официальном GenAI Crosswalk](https://genai-security-project.github.io/crosswalk/agentic-ai-top10/).

## Основные идеи

| Код | Риск, краткий пересказ |
| --- | --- |
| ASI01 | Перенаправление целей агента атакующим |
| ASI02 | Злоупотребление легитимными инструментами |
| ASI03 | Использование идентичности и прав за пределами разрешённого |
| ASI04 | Компрометация зависимостей, инструментов и шаблонов агента |
| ASI05 | Исполнение кода, навязанного атакующим |
| ASI06 | Устойчивое отравление памяти и контекста |
| ASI07 | Небезопасный обмен сообщениями между агентами |
| ASI08 | Распространение сбоя по цепочке агентов |
| ASI09 | Манипуляция доверием человека к агенту |
| ASI10 | Агенты, скрыто действующие вопреки назначению |

Основание: раздел «The 10 Agentic AI risk categories» официального Crosswalk.

## Для проекта

Интерпретация для нашего кейса: инъекции в метаданных связаны с ASI01/06;
генерация и запуск кода — ASI05; цепочки агентов — ASI07/08;
формальный аппрув человека — ASI09; общий фреймворк — ASI04.
