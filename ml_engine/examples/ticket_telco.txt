Тикет CRM-4821. Отдел удержания клиентов.

Хотим понимать, какие абоненты скоро уйдут, чтобы заранее звонить им с
удерживающим предложением. Во вложении выгрузка по клиентам за квартал: кто ушёл,
а кто остался, видно по колонке Churn Value (1 = ушёл).
Нужна модель, которая ранжирует клиентов по риску ухода. Звонить будем топ-10% списка.
Пол клиента по закону использовать нельзя.
